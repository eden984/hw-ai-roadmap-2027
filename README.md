# H/W 개발자 × AI 협업 로드맵 2027

## 👉 [사이트 보러가기](https://eden984.github.io/hw-ai-roadmap-2027/)

H/W 개발 업무 55개(IoT 로거 고유 업무 7개 포함)를 7개 변수로 점수화해 탐색적 데이터 분석(EDA)을 하고, 그 결과로 2027년 분기별 AI 협업 로드맵을 만들었다.

- 2027년에 AI로 줄일 수 있는 시간은 주 14.2시간으로, 전체의 30%다. 상위 10개 업무가 절감 몫의 39%를 차지한다.
- 2027년 AI 역량을 가장 잘 설명하는 변수는 사내 데이터 준비도(r=+0.83)와 오류 비용(r=-0.69)이다.
- 2027년 로드맵: Q1 안전·보안 규칙과 데이터 쌓기부터 + 반복 업무 맡기기 → Q2 AI 초안과 사람 검증 → Q3 쌓은 데이터 연결 → Q4 점검·재투자
- 백색가전 H/W 개발자와의 차별화 전략 4가지
- 공개 통계 4개(Stack Overflow 2025, Black Duck, RunSafe)를 외부 지표로 붙였다
- 5-Color 4인 리뷰(RED·SILVER·BLUE·GOLD)를 여러 차례 받아 반영했다(6.0 → 8.0 → 8.8 → 9.4, 4차 지적까지 반영)
- 1분 영상: 키네틱 타이포와 라인 아트, 한국어 내레이션 (`roadmap_2027.mp4`)

> 데이터는 실측 설문이 아니라 본 분석의 가정 점수다(`data.csv`). 방법론은 사이트 하단에 있다.
