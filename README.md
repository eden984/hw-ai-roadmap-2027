# H/W 개발자 × AI 협업 로드맵 2027

## 👉 [사이트 보러가기](https://eden984.github.io/hw-ai-roadmap-2027/)

H/W 개발 업무 48개를 7개 변수로 점수화해 탐색적 데이터 분석(EDA)을 하고, 그 결과로 2027년 분기별 AI 협업 로드맵을 만들었다.

- 2027년에 AI로 줄일 수 있는 시간은 주 13.6시간으로, 전체의 34%다. 상위 10개 업무가 절감 몫의 45%를 차지한다.
- 2027년 AI 역량을 가장 잘 설명하는 변수는 사내 데이터 준비도(r=+0.86)와 오류 비용(r=-0.76)이다.
- 2027년 로드맵: Q1 맡기기 → Q2 AI 초안과 사람 검증 → Q3 데이터 쌓기 → Q4 사람 판단 영역 명문화
- 백색가전 H/W 개발자와의 차별화 전략 4가지
- 1분 영상: 키네틱 타이포와 라인 아트, 한국어 내레이션 (`roadmap_2027.mp4`)

> 데이터는 실측 설문이 아니라 본 분석의 가정 점수다(`data.csv`). 방법론은 사이트 하단에 있다.
